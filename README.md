# Sample–Superstore 商业数据分析与可视化大屏

> 《商业数据分析》期末大作业｜数据来源：Tableau 官方示例数据集 Sample – Superstore
> 全流程 Python 实现：数据获取 → 清洗治理 → 商业模型 → 图表复现 → 交互大屏 → 商业洞察

---

## 1. 项目简介

本项目以美国零售企业 **Sample – Superstore** 2023–2026 年的 10,194 条订单明细为对象，回答三个商业问题：

1. **钱从哪来**：哪些产品子类、大区、客群贡献了主要销售额与利润？
2. **客户值多少、会不会走**：客户价值如何分层？留存曲线长什么样？谁需要召回？
3. **下一步怎么打**：折扣红线在哪？未来 6 个月销售会走到什么水平？

最终产出 **26 张静态图表（25 张正文用图 + 1 张附录大屏截图）+ 1 个交互式暗色大屏 + 24 张模型结果表 + 1 篇期末论文**，构成从数据到决策的完整链条。

## 5. 商业分析模型清单（2.2 要求 ≥3 种，实际 7 类 / 9 个）

| 编号 | 模型 | 类别 | 参数与阈值设定依据 | 对应图 |
| --- | --- | --- | --- | --- |
| M1 | 同比 / 环比 + 3 期移动平均 | 趋势与对比 | 同比取隔 12 个月对比，消除季节性；MA3 窗口=3，覆盖一个季度且不至于过度平滑 | fig15 |
| M2 | 帕累托 / ABC 分类 | 结构与价值 | 70%/90% 为库存 ABC 管理的行业惯例切分，比 80/20 更利于锁定现金流核心 | fig16 |
| M3 | RFM 八分类 | 用户与客群 | R/F/M 三项右偏，用**中位数**切分保证高低组各约 50%，避免均值被大客户拉高 | fig17 |
| M4 | K-Means 用户分群 | 用户与客群 | log1p 压缩右偏 + Z-score；K 在 3~6 用轮廓系数择优（下限 3 保证可运营） | fig18 |
| M5 | 同期群留存 | 用户与客群 | 以首购月建群，仅保留群规模 ≥20 的同期群，过滤小样本噪声 | fig19 |
| M6 | 波士顿矩阵 | 结构与价值 | 取 2025/2026 两个**完整自然年**；分界线=平均份额（5.88%）与整体增速（21.44%） | fig20 |
| M7 | SARIMA / Holt-Winters 比选 | 预测与预警 | 网格搜 AIC 定阶；以**样本外 6 个月 MAPE** 择优；输出点预测 + 95% 置信区间 + RMSE/MAE | fig21 |
| M8 | Apriori 关联规则 | 关联与转化 | 订单=购物篮、子类=商品；支持度 0.6%、置信度 15%、仅保留 lift>1 | fig22 |
| M9 | 漏斗转化 | 关联与转化 | 订单级四级漏斗：下单→按时履约→未退货→盈利 | fig23 |

**关键模型结果**

- **帕累托**：A 类 6 个子类（占 17 个的 35%）贡献 64.4% 销售额，前 3 名（座椅/手机/收纳存储）即占 38.4%。
- **RFM**：`重要价值客户` 204 人（25.4%）贡献 40.2% 销售额；`重要唤回客户` 116 人贡献 24.3% 但平均 174 天未回购 —— 召回优先级最高。
- **K-Means**（K=3，轮廓系数 0.262）：核心高价值群 37.4% 客户 / 48.8% 销售额；沉睡高额群 43.5% 客户 / 47.4% 销售额但平均 189 天未活跃。
- **同期群**：首月留存平均 11.7%，其后稳定在 8%–11%，没有出现断崖式流失，说明复购是被"月均一单"的常规节奏驱动。
- **波士顿矩阵**：手机/装订用品/复印机/配件属明星业务（复印机毛利率 39.8%）；桌子（-13.3%）、机器设备（-6.5%）是"份额高但在亏钱"的伪现金牛。
- **预测**：Holt-Winters（加性·阻尼）胜出，回测 MAPE **16.93%**、RMSE 19,886 美元，优于 SARIMA(2,1,2)(0,1,1,12) 的 25.36%；2027 年上半年月均预测 6.18 万美元，较 2026 年（6.21 万）基本持平（-0.6%），**增长进入平台期**。
- **关联规则**：93 条有效规则，"家居陈设+装订用品→小家电"（lift 1.89）、"手机+收纳存储→家居陈设"（lift 1.81）最强，可做组合陈列与凑单推荐。
- **折扣弹性**：无折扣时毛利率 29.6%，10–20% 档降至 11.5%，**超过 20% 直接转负（-10.1%），该档 91.7% 的明细在亏钱**；40% 以上亏损占比 100% —— 折扣红线建议设在 **20%**。

### 6.3 交互式大屏

**主大屏**：`dashboard/商业分析大屏.html`（双击即可打开，ECharts 已本地化，无需联网）

组件：5 个 KPI 卡 + 8 个图表 + 1 张明细表 + 3 个筛选器 = **17 个组件**

联动机制：
- 筛选「年份 / 大区 / 品类」→ 全部 KPI、趋势、结构、大区、帕累托、明细表实时重算；
- 点击品类环形图扇区 / 大区柱形 → 写入筛选条件并全局下钻；
- 点击「重置筛选」回到全量口径。

## 8. 技术要点

- **全 Python 出图**：Matplotlib 自绘渐变柱、圆角柱、水球、玫瑰、仪表盘等非标准图形（`viz_helpers.py`），不依赖图表插件或 Excel。
- **中文规范**：统一 Microsoft YaHei，`axes.unicode_minus=False` 解决负号乱码；维度字段全部映射为中文，图表内无英文。
- **可复现**：固定随机种子（K-Means `random_state=42`、RFM 抖动 `default_rng(42)`），一键脚本 + requirements 锁定版本。
- **大屏无外部依赖**：ECharts 静态库随项目落地，断网也能演示。
